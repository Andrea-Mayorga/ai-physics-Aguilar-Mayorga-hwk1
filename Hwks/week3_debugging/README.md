# Debugging an AI-generated quantum harmonic oscillator

Homework 3 (Week 03), Generative AI in Physics.

The starting point is `ai_generated_oscillator.py`, a script produced by an LLM. It should compute and plot the first five energy levels and wavefunctions of the 1D quantum harmonic oscillator, but it contains five bugs. This folder documents the bugs, fixes them, and adds a pytest suite that catches all five. It then uses that suite as the specification for test-driven prompting: an LLM regenerates the script from scratch, and the result is checked against the suite.

## The five bugs

| Bug | Category | What was wrong |
|---|---|---|
| #1 | Wrong physics formula | E_n = n ħω instead of (n + ½) ħω |
| #2 | Off-by-one error | `states[1:]` dropped the ground state, so only 4 levels were plotted |
| #3 | Hallucinated API | `scipy.special.hermite_poly` does not exist |
| #4 | Incorrect normalization | 1/√(n!) instead of (2ⁿ n! √π)^(−1/2) |
| #5 | Wrong output quantity | Plotted ψ instead of the probability density \|ψ\|² |

The bug report has the details and the line numbers.

## The test suite

The physical specification is in dimensionless units, ħ = m = ω = 1:

- E_n = (n + ½) ħω (Griffiths eq. 2.50)
- ψ_n(x) = (2ⁿ n!)^(−1/2) π^(−1/4) H_n(x) e^(−x²/2), with the physicists' Hermite polynomials (Griffiths eq. 2.69)
- ⟨ψ_m|ψ_n⟩ = δ_mn
- `main()` plots \|ψ_n\|² for n = 0, …, 4

Each test has a docstring stating the physical property it checks. The suite is grouped by bug:

| Group | What the tests check |
|---|---|
| Bug #1 | The energy values, a zero-point energy different from zero, and scaling with ħω |
| Bug #3 | `harmonic_state` runs, and ψ₂ follows the physicists' H₂ = 4x² − 2 (not He₂ = x² − 1) |
| Bug #4 | ∫\|ψ_n\|² dx = 1 for n = 0, …, 4, and ψ₀(0) = π^(−1/4) |
| Extra | Orthogonality of the states, the weighted orthogonality constants of H_n, and parity |
| Bug #2 | `main()` draws exactly 5 curves, and the first one is \|ψ₀\|² |
| Bug #5 | Every plotted curve is non-negative and equals \|ψ_n\|² |

The "Extra" tests were left out of the prompt on purpose. They serve as held-out tests: the model never saw them, so they check whether the regenerated code is physically correct beyond the tests it was given (Mathews & Nagappan, [arXiv:2402.13521](https://arxiv.org/abs/2402.13521)).

## Results

| Module tested | Result |
|---|---|
| `ai_generated_oscillator_original.py` | 29 failed, 3 errors |
| `ai_generated_oscillator_fixed.py` | 32 passed |
| `AI_test_driven_oscillator.py` (GPT-6) | 32 passed, including the held-out tests |

The 3 errors come from the `AttributeError` raised by `hermite_poly` (bug #3), which stops `main()` before it can draw anything.

## How to run

Requirements: Python 3.10 or later, with numpy 2.x (the tests use `np.trapezoid`), scipy, matplotlib and pytest. The results above were obtained with Python 3.11.16, numpy 2.4.6, scipy 1.17.1, matplotlib 3.11.2 and pytest 9.1.1.

From this folder, run the suite against the fixed version (the default):

```bash
python -m pytest -v
```

The environment variable `OSC_MODULE` chooses another module:

```bash
OSC_MODULE=ai_generated_oscillator_original python -m pytest -v
```

```bash
OSC_MODULE=AI_test_driven_oscillator python -m pytest -v
```

You can also open the notebook and run all cells. The `%%writefile` cells write `conftest.py`, `test_oscillator.py` and `AI_test_driven_oscillator.py` before the tests run.
